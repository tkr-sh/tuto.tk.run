## Python

- Python は Lua に比べて、説明しなければならないことが多すぎます。一度もプログラミングをしたことがない人に、すべてのキーワードを説明してみてください。うまくいくことを祈ります。
- なぜスペースとタブを混ぜてはいけないのか（そもそもタブ `\t` とは何なのか？）を説明してみてください。うまくいくことを祈ります。
- 外部依存のあるプログラムを実行するためだけに、仮想環境をインストールする必要があると説明してみてください。うまくいくことを祈ります。
- try/except によるエラー処理とは何かを説明してみてください。うまくいくことを祈ります。
- for ループ、リスト内包表記、map のどれを使うべきかを説明してみてください。さらに「lambda」の意味は？ うまくいくことを祈ります。
- OOP とは何か、なぜそれが「便利」なのかを説明してみてください。うまくいくことを祈ります。
- セイウチ演算子 `:=` についても、うまくいくことを祈ります。
- さらに、ほとんどすべての演算子に代入演算子があること（`+=`、`-=` など）も説明しなければなりません。

たとえば……これらすべてを教えることは不可能ではありません。ただ、Lua では考えなくてもよい余分なものが増えるだけなのです。
