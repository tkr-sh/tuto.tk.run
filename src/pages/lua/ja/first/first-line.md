```lua
number_of_tries = 0
```

これはプログラムで最初に目にする行です。

ふつう、プログラムが何をしているのか理解したいときは、普通の英文を読むように一行ずつ読みます。ですからここから始めましょう。


## なるほど、でもこの行は何をしているの？

プログラミング言語では、よく「変数」という概念が出てきます。変数は、データを入れておくラベルの付いた箱のようなものです。一度変数を作れば、その中身を読むことができ（箱を開けるのと同じです）、さらに変更することもできます（「変数」という名前のとおりです）。これは箱に新しい値を入れるのと同じです。

### でも、どんなデータなの？

Lua には、今のところ知っておくべきデータ型が 6[^1] 種類あります。
- `number`：数学の数と同じです！ 単に書くだけで数値を宣言できます：`123`。<br/> **注意**：小数を含む数（例：`0.5`）には、`,`（カンマ）ではなく `.`（ドット）を使ってください。
- `boolean`：`true` か `false` のどちらかです（例：「2 は 3 と等しい？」=> `false`）。
- `nil`：空。`nil` の目的は、値がないことを表すことです。
- `string`：文字、数字、記号の集まりです（例：`こんにちは！`）。文字列を宣言するには、内容を引用符（`'` または `"`）で囲む必要があります（例：文字列 `こんにちは！` を得るには `"こんにちは！"` と書きます）。
- `table`：後で見ていきます！
- `function`：後で見ていきます！

変数にデータを代入したいときは、次のように書くだけです。
```lua
the_name_of_the_variable = the_value
```
`the_name_of_the_variable` は何でもかまいません。ただし `true`、`false`、`nil`（および後で出てくるその他のもの）は除きます。

`the_value` は上で説明した有効な値です。

いくつか例を挙げます。
```lua
a_negative_number = -1
a_big_number = 100000000
grandpa_name = "太郎"
no_value = nil
is_it_raining = false
```

変数の内容を別の変数に代入することもできます。

```lua
grandpa_name = "太郎"
my_grandpa_friend_name = grandpa_name
```

この場合、`grandpa_name` と `my_grandpa_friend_name` はどちらも文字列 `太郎` になります。

## 最初の行に戻りましょう

```lua
number_of_tries = 0
```

つまり、この行は単に数値 `0` を変数 `number_of_tries` に入れているだけです。これは実に理にかなっています！ プログラムの開始時点では、ユーザーはまだ数を当てようとしていませんからね！ そして `number_of_tries` という名前が示すとおり、この変数は今後、ユーザーが行った試行回数を保持することになります！
