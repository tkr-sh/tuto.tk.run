```lua
number_to_guess = random(1, 100)
```

さて、変数にデータを入れられることはわかりました……でもこれは何でしょうか？？？

これが何をしているのか理解するには、`function`（関数）を理解する必要があります。これは最初の行の説明で触れなかったデータ型の一つなので、ここで説明します。

関数は、何か入力を受け取り、それを使って何かをし、その結果を出力として返す機械のようなものだと考えられます。

## でも、入力を使って何をするの？？

Lua には、特別なことをするための演算子がいくつかあります。

- `+`：2 つの数値を足します。（例：`1 + 2` => `3`）
- `-`：ある数値から別の数値を引きます。（例：`3 - 2` => `1`）
- `*`：2 つの数値を掛けます。（例：`3 * 2` => `6`）
- `/`：ある数値を別の数値で割ります。（例：`6 / 2` => `3`）

したがって、変数を使って次のようなことができます。
```lua
the_best_number = 40 + 2
my_grandpa_age = the_best_number * 2
```

`the_best_number` は 42 になり、`my_grandpa_age` は 84 になります。

## 関数に戻りましょう！

たとえば、関数は数値を受け取り、その数値に `+ 1` した結果を返すことができます。

関数は変数と同じように、名前を知っていれば使えます。しかし！ 関数に処理を実行させて出力を受け取るには、名前の後ろに括弧を付ける必要があります（例：`my_function()`）。これは `my_function` という名前の関数を実行します。ただし、この関数には入力がありません！ 入力を持たせるには、括弧の中に渡したい値を入れ、`,` で区切ります。

### 例

```lua
day = 4
month = "4月"
year = 1984
calculate_tomorrows_date(day, month, year)
```
これは次と同じです。
```lua
calculate_tomorrows_date(4, "4月", 1984)
```

## 2 行目に戻りましょう

```lua
number_to_guess = random(1, 100)
```

つまり、この行は関数 `random` を入力 `1` と `100` で実行し、その計算結果を `number_to_guess` に入れています。`random` が何をするのかは定義していません。しかし、Lua には開発者を助けるための組み込み関数がいくつか用意されています！ 今回の場合、`random` という関数があり、2 つの数値を入力として受け取り、最初の数値（ここでは `1`）と 2 つ目の数値（ここでは `100`）の間のランダムな数値を生成します。

完璧です！ これでユーザーが当てるべき数値が生成されました！
