今回初めて、単一の行に注目するのではありません！ 現在の行はただの

```lua
repeat
```

ですが、それ自体では何もしません。`until` と一緒に使います。

```lua
repeat
	user_guess = tonumber(read())
	number_of_tries = number_of_tries + 1

	if number_to_guess < user_guess then
		print("もっと小さい数です！")
	end

	if number_to_guess > user_guess then
		print("もっと大きい数です！")
	end
until user_guess == number_to_guess
```

でもまず最初に……`repeat` と `until` とは何で、なぜそんなに特別なのでしょうか？ 単なる変わった変数ではないのでしょうか？

変数の定義を覚えているかもしれません。

> `the_name_of_the_variable` は何でもかまいません。ただし `true`、`false`、`nil`（および後で出てくるその他のもの）は除きます。

そして「後で」……それが今です！

## キーワード

`repeat` と `until` は「キーワード」と呼ばれるものです。キーワードは特別な名前で、変数のように値を持ったり、関数のように計算を行ったりするのではなく、Lua に特定の決定をさせる命令です。

`repeat`/`until` の例では、`repeat` と `until` の間にあるすべてのものが、ある条件を満たすまで繰り返されます。実行が `until` に到達すると、再実行するかどうかを確認し、必要ならコードは `repeat` に戻って繰り返します。

このような動作——_何か_ が起こるまでコードを繰り返すこと——は「ループ」と呼ばれ、プログラミングで非常によくある概念です。

ほとんどの場合、あなたはある時点でループを抜けたいと思うでしょう……

### でも、いつ抜けるべきかはどうやってわかる？

`until` のようなループを使うときは、いつループを止めるべきかを伝えるために `boolean`（`true` または `false`）を渡す必要があります。

そしてほとんどの場合、それは関係演算子を使って行います。

- `==`：2 つの値が等しいかを確認します。**1 つの `=` と混同しないでください**。1 つの `=` は値の代入、2 つの `=`（`==`）は 2 つの値が等しいかの確認です。同じなら値は `true`、そうでなければ `false` です。
- `~=`：2 つの値が異なるかを確認します。異なるなら値は `true`、そうでなければ `false` です。
- `>`：左の値が右の値より大きいかを確認します。そうなら値は `true`、そうでなければ `false` です。
- `<`：左の値が右の値より小さいかを確認します。そうなら値は `true`、そうでなければ `false` です。
- `>=`：左の値が右の値より大きい**か等しい**かを確認します。そうなら値は `true`、そうでなければ `false` です。
- `<=`：左の値が右の値より小さい**か等しい**かを確認します。そうなら値は `true`、そうでなければ `false` です。


<div class="runner">

```lua
print(1984 == 2025)
print(1984 ~= 2025)
print(1984 < 2025)
print(2025 <= 2025)
print(2025 < 2025)
print(1984 > 2025)
```

</div>

### ループの種類

- `repeat`/`until`：ある条件を満たすまでコードを繰り返し、条件を満たすと停止します。

<div class="runner">

```lua
age = 0
repeat
    print(age)
    age = age + 1
until age == 4
```
</div>

- `while`：while ループは `repeat`/`until` ループと非常によく似ていますが、逆です！ 条件を満たしている間ループします！ 条件の後に `do` キーワードを使ってコードの実行を開始し、`end` キーワードを見ると先頭に戻ってループします。`repeat` を使えるほとんどの場面で `while` も使えます。主に好みの問題です。

<div class="runner">

```lua
age = 0
while age ~= 4 do
    print(age)
    age = age + 1
end
```
</div>

- `for`：最後のループは `for` ループで、少し異なります。何回繰り返したいかをあらかじめ知っているからです。どの数値からどの数値まで繰り返すかを定義します。反復の終わりに、自動的に `age` を `1` 増やします！

<div class="runner">

```lua
for age = 0, 3 do
    print(age)
end
```
</div>
