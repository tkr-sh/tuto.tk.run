テーブルを扱うときに知っておくと便利な情報の一つに、「要素がいくつあるか？」があります。たとえば、最後の要素を取得したいときです！

これは特別な演算子 `#` で可能になります。`#` の後にテーブル名、またはテーブルそのものを書くことで、テーブルの全長を得られます。


<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(#my_table)
my_table[4] = "d"
print(#my_table)
```

</div>

これは特に、「最後の」インデックスにあるテーブルの要素を知りたいときや、末尾に新しい要素を追加したいときに便利です。`my_table[#my_table]` は、キーがテーブルの全長である値、つまりほとんどの場合で最後の要素です！

<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(my_table[#my_table])
my_table[#my_table + 1] = "d"
print(my_table[#my_table])
```

</div>


### エッジケース

`#` 演算子が信頼できるのは、テーブルのキーが `1` から始まり、隙間のない整数 `1, 2, 3, ...` である場合だけです。文字列やブール値のキーは数えられず、途中に数値が欠けていると結果は予測できません。

<div class="runner">

```lua
-- 信頼できる：キーは 1, 2, 3
print(#{ "a", "b", "c" }) -- 3
print(#{ [1] = "a", [2] = "b", [3] = "c" }) -- 3

-- 数えられない：キーは文字列
print(#{ ["a"] = 1, ["b"] = 2, ["c"] = 3 }) -- 0

-- 信頼できない：インデックス 2 に隙間がある
print(#{ [1] = "a", [3] = "b", [4] = "c" }) -- 1 または 4、頼りにしないでください
```

</div>
