テーブルを扱うもう一つの鍵は、テーブルを反復処理することです。ゲームに `scores` テーブルがあるとします（各 `score` は、ユーザーが数値を見つけるのにかかった `number_of_tries` です）。各ゲームの各スコアをどうやって表示しますか？

## `for index`
まず、以前に簡単に話した `for` キーワードを覚えているかもしれません。

<blockquote>

`for`：最後のループは `for` ループで、少し異なります。何回繰り返したいかをあらかじめ知っているからです。どの数値からどの数値まで繰り返すかを定義します。反復の終わりに、自動的に `age` を `1` 増やします！

<div class="runner">

```lua
for age = 0, 3 do
    print(age)
end
```
</div>

</blockquote>

これを `#` 演算子の新しい知識と結びつければ、テーブルをうまく反復処理できます！

<div class="runner">

```lua
scores = {
    [1] = 7,
    [2] = 8,
    [3] = 4,
}

for key = 1, #scores do
    print(key .. ": " .. scores[key])
end
```
</div>

これはうまく機能します！ ただし、値を取得するために常に `scores[key]` と書くのは少し冗長です。特にキーに興味がなかったり、もうテーブルを使う予定がなかったりする場合はそうです。幸い、Lua にはこれを扱う別の方法があります。

## `ipairs`

`ipairs` は、`for` キーワードと一緒に使う関数で、テーブル名を参照せずにキーと値へ素早くアクセスできます！ 構文は以前の `for` ループとは少し異なりますが、やはり `for` キーワードを使います。

```lua
for my_key, my_value in ipairs(my_table) do 
    -- 何かをする！
end
```

この例では、`my_table` という名前の `table` があると仮定します。`for` と `end` の間にあるすべてのコード行は、`my_key` と `my_value` がそれぞれ `my_table` のキーと対応する値として実行されます。

以前の `for` ループと同様に、昇順で並びます。つまり `1` から始まり、反復ごとに `1` ずつ増えます。ただし、キーが `string` の場合や、数値の間に隙間がある場合は機能しません。その場合は `pairs` を使うべきです。

## `pairs`

`pairs` は `ipairs` に似ていますが、`1` から始まる連続した整数ではないキーでも機能する点が異なります。欠点は、キーが現れる順序が信頼できないことです。

<div class="runner">

```lua
my_table = {
    [3] = 7,
    ["name"] = 8,
    [false] = 4,
}

for key, value in pairs(my_table) do
    print(key)
    print(value)
end
```

</div>

キー/値が表示される順序は信頼できず、実行するたびに変わる可能性があります。ただし、すべてのテーブルを反復処理できるという利点があります！

## ゲームに戻りましょう
今回の場合、ゲームごとの `number_of_tries` を記録しておきたいだけです。したがって、カスタムキーは必要なく、インデックスを `1` から始めて毎回 `1` ずつ増やし、ゲーム番号に対応させればよいだけです！
