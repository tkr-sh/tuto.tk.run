Este tutorial é um tutorial sobre a linguagem de programação «Lua».

Este tutorial é destinado a pessoas que nunca programaram e que querem aprender como fazer, ou que são apenas curiosas.

Este guia não exige nenhum conhecimento prévio em programação, matemática, física ou algoritmia. A única coisa importante é um conhecimento básico de inglês (conhecer palavras como «if», «else», «end», «repeat», «while», ...).

Uma coisa que eu realmente aconselho você a fazer é: NÃO USE NENHUMA IA. Tente aprender tudo sozinho e com este tutorial. Este tutorial foi feito para que você aprenda as coisas numa ordem específica e não exige nenhuma IA.

Este guia permitirá que você execute seu próprio programa Lua no site, para aprender a linguagem de forma interativa, então não se preocupe com «como instalar o Lua?» por enquanto.

Então, sem mais demora, _**vamos começar!**_

Algumas pessoas podem perguntar por que este tutorial é sobre Lua e não Python ou Javascript. Aqui está a minha resposta:

## Python

- O Python tem coisas demais em comparação com o Lua. Boa sorte explicando todas as palavras-chave para alguém que nunca programou.
- Boa sorte explicando por que você não pode misturar espaços e tabulações (e o que são mesmo as tabulações `\t`?).
- Boa sorte explicando às pessoas que elas precisam instalar um ambiente virtual só para executar seu programa com dependências externas.
- Boa sorte explicando o que é tratamento de erros com try/except.
- Boa sorte explicando se você deve usar um laço for, list comprehensions ou map, e o que «lambda» significa.
- Boa sorte explicando o que é OOP e por que é «útil».
- E boa sorte com o operador morsa (walrus) `:=`.
- Além disso, você tem que explicar que existem operadores de atribuição para quase todos os operadores (`+=`, `-=`, etc.).

Assim... tudo isso não é impossível de ensinar. Mas são só mais coisas com que você não precisa se preocupar em Lua.
