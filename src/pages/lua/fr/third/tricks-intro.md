Maintenant que nous avons un jeu fonctionnel avec davantage de fonctionnalités, nous allons examiner quelques petites astuces Lua. Elles vous aideront à écrire un meilleur code et à comprendre le code des autres !

D'abord, nous devons introduire le concept de « sucre syntaxique ». Le sucre syntaxique est une façon plus courte ou plus agréable d'écrire quelque chose que le langage sait déjà faire. Il n'ajoute aucune nouvelle capacité, il rend seulement le code plus « sucré » à lire et à écrire, d'où son nom. Quand Lua voit le sucre, il le traite exactement comme si vous aviez écrit la version longue.

L'objectif de ce chapitre est de vous apprendre quelques sucres syntaxiques et de vous montrer davantage de fonctions intégrées de Lua. Nous passerons en revue les types un par un, avec une page pour chacun.
