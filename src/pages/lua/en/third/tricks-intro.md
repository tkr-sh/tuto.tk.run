Now that we have a working game with more features, we will look at some small Lua tricks. They will help you write better code and understand the code of others!

First, we need to introduce the concept of "syntactic sugar". Syntactic sugar is a shorter or nicer way to write something the language can already do. It doesn't add any new ability, it only makes the code "sweeter" to read and write, hence the name. When Lua sees the sugar, it treats it exactly as if you had written the longer version.

The goal of this chapter is to teach you some syntactic sugar and to show you more of Lua's built-in functions. We will go through the types one by one, with one page for each.
