```lua
number_to_guess = random(1, 100)
```

好，我们刚刚看到可以把一些数据放进变量里……但这又是什么？？？

要理解这行在做什么，我们需要理解 `function`（函数）。这是我在讲第一行时没有解释的数据类型之一，所以现在来说说：

你可以把函数看作一种机器：它接收一些输入，对输入做一些处理，然后给你一个输出。

## 但它对输入做了什么？？

在 Lua 中，有一些运算符可以让你做特殊的事情：

- `+`：将两个数字相加。（例如：`1 + 2` => `3`）
- `-`：从一个数字中减去另一个数字。（例如：`3 - 2` => `1`）
- `*`：将两个数字相乘。（例如：`3 * 2` => `6`）
- `/`：用一个数字除以另一个数字。（例如：`6 / 2` => `3`）

因此，我们可以对变量做以下事情
```lua
the_best_number = 40 + 2
my_grandpa_age = the_best_number * 2
```

`the_best_number` 会是 42，`my_grandpa_age` 会是 84。

## 回到我们的函数！

例如，一个函数可以接收一个数字，并返回这个数字 `+ 1` 的结果。

函数和变量一样，知道它的名字就可以使用它。但是！当你希望它执行处理并给你输出时，你必须在名字后面加上括号（例如 `my_function()`）。这会执行一个名为 `my_function` 的函数。但这个函数没有任何输入！要给它添加输入，你可以把想要的值放在括号之间，并用 `,` 分隔。

### 例子

```lua
day = 4
month = "四月"
year = 1984
calculate_tomorrows_date(day, month, year)
```
这等同于
```lua
calculate_tomorrows_date(4, "四月", 1984)
```

## 回到我们的第二行

```lua
number_to_guess = random(1, 100)
```

所以，这一行执行函数 `random`，输入为：`1` 和 `100`，并把计算结果放进 `number_to_guess`。我们从未定义过 `random` 做什么。但 Lua 自带一些内置函数来帮助开发者！在我们的例子中，有一个 `random` 函数，它需要两个数字作为输入，并在第一个数字（这里是 `1`）和第二个数字（这里是 `100`）之间生成一个随机数。

完美！现在我们已经生成了用户需要猜的数字！
