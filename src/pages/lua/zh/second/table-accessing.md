在处理表时，我们经常需要知道的一条有用信息是“它有多少个元素？”例如，如果我想获取最后一个元素！

这可以通过一个特殊运算符实现：`#`。通过写 `#`，然后写表名或直接写表，你可以得到表的总长度：


<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(#my_table)
my_table[4] = "d"
print(#my_table)
```

</div>

如果我想知道表中“最后一个”索引对应的元素，或者想在末尾添加一个新元素，这会特别有用：`my_table[#my_table]` 的值对应的键是表的总长度，在大多数情况下也就是最后一个元素！

<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(my_table[#my_table])
my_table[#my_table + 1] = "d"
print(my_table[#my_table])
```

</div>


### 边界情况

只有当表的键是从 `1` 开始且没有缺口的整数 `1, 2, 3, ...` 时，`#` 运算符才是可靠的。字符串或布尔值键不会被计入，如果中间缺少某个数字，结果则不可预测：

<div class="runner">

```lua
-- 可靠：键是 1, 2, 3
print(#{ "a", "b", "c" }) -- 3
print(#{ [1] = "a", [2] = "b", [3] = "c" }) -- 3

-- 不会被计入：键是字符串
print(#{ ["a"] = 1, ["b"] = 2, ["c"] = 3 }) -- 0

-- 不可靠：索引 2 处有缺口
print(#{ [1] = "a", [3] = "b", [4] = "c" }) -- 1 或 4，不要依赖它
```

</div>
