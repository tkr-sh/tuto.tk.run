本教程是关于“Lua”编程语言的教程。

本教程面向从未编程过、想要学习编程或只是出于好奇的人。

本指南不需要任何编程、数学、物理或算法方面的基础知识。唯一重要的是具备基本的英语知识（认识“if”“else”“end”“repeat”“while”等单词）。

我强烈建议你：不要使用任何 AI。尝试完全靠自己、借助本教程来学习所有内容。本教程的设计目的是让你按照特定顺序学习，并且不需要任何 AI。

本指南会让你在网站中运行自己的 Lua 程序，从而以交互方式学习这门语言，所以现在不用担心“我该怎么安装 Lua？”。

那么，不再等待，_**让我们开始吧！**_

有些人可能会问，为什么讲的是 Lua 而不是 Python 或 JavaScript，以下是我的回答：

## Python

- 与 Lua 相比，Python 要讲的东西实在太多了。祝你向一个从未编程过的人解释清楚所有关键字时好运。
- 祝你好运去解释为什么不能混用空格和制表符（以及制表符 `\t` 到底是什么？）
- 祝你好运去向人们解释，他们仅仅为了用外部依赖运行程序就得安装一个虚拟环境。
- 祝你好运去解释 try/except 的错误处理是什么。
- 祝你好运去解释到底该用 for 循环、列表推导式还是 map？还有“lambda”是什么意思？
- 祝你好运去解释 OOP 到底是什么，以及它为什么“有用”。
- 还有海象运算符 `:=`，也祝你好运。
- 另外你还得解释几乎每个运算符都有对应的赋值运算符（`+=`、`-=` 等）。

比如……这些都不是不能教。只是在 Lua 里，你不需要考虑那么多额外的东西。
