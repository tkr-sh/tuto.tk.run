테이블을 다룰 때 알아 두면 유용한 정보 중 하나는 "요소가 몇 개인가?"입니다. 예를 들어 마지막 요소를 가져오고 싶을 때요!

이것은 특별한 연산자 `#`로 가능합니다. `#` 뒤에 테이블 이름이나 테이블 자체를 쓰면 테이블의 전체 크기를 얻을 수 있습니다.


<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(#my_table)
my_table[4] = "d"
print(#my_table)
```

</div>

이것은 특히 "마지막" 인덱스에 있는 테이블 요소를 알고 싶을 때, 또는 끝에 새 요소를 추가하고 싶을 때 유용합니다. `my_table[#my_table]`은 키가 테이블 전체 길이인 값, 즉 대부분의 경우 마지막 요소입니다!

<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(my_table[#my_table])
my_table[#my_table + 1] = "d"
print(my_table[#my_table])
```

</div>


### 경계 사례

`#` 연산자는 테이블의 키가 `1`부터 시작하고 빈틈없는 정수 `1, 2, 3, ...`일 때만 신뢰할 수 있습니다. 문자열이나 부울 키는 계산되지 않으며, 중간에 숫자가 빠져 있으면 결과를 예측할 수 없습니다.

<div class="runner">

```lua
-- 신뢰 가능: 키는 1, 2, 3
print(#{ "a", "b", "c" }) -- 3
print(#{ [1] = "a", [2] = "b", [3] = "c" }) -- 3

-- 계산되지 않음: 키는 문자열
print(#{ ["a"] = 1, ["b"] = 2, ["c"] = 3 }) -- 0

-- 신뢰 불가: 인덱스 2에 빈틈이 있음
print(#{ [1] = "a", [3] = "b", [4] = "c" }) -- 1 또는 4, 의존하지 마세요
```

</div>
