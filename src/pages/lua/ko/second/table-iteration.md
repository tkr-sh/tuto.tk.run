테이블을 다루는 또 다른 핵심은 테이블을 순회하는 것입니다. 우리 게임에 `scores` 테이블이 있다고 합시다(각 `score`는 사용자가 숫자를 찾는 데 걸린 `number_of_tries`입니다). 각 게임의 각 점수를 어떻게 보여 줄까요?

## `for index`
먼저, 예전에 간단히 이야기했던 `for` 키워드를 기억할지도 모르겠습니다.

<blockquote>

`for`: 마지막 루프는 `for` 루프이고 조금 다릅니다. 얼마나 반복할지 이미 알고 있기 때문입니다. 어떤 숫자에서 어떤 숫자까지 반복할지 정의합니다. 한 번의 반복이 끝나면 자동으로 `age`를 `1` 증가시킵니다!

<div class="runner">

```lua
for age = 0, 3 do
    print(age)
end
```
</div>

</blockquote>

이것을 `#` 연산자에 대한 새로운 지식과 연결하면 테이블을 성공적으로 순회할 수 있습니다!

<div class="runner">

```lua
scores = {
    [1] = 7,
    [2] = 8,
    [3] = 4,
}

for key = 1, #scores do
    print(key .. ": " .. scores[key])
end
```
</div>

이것은 아주 잘 작동합니다! 하지만 값을 얻기 위해 항상 `scores[key]`라고 쓰는 것은 다소 중복될 수 있습니다. 특히 키에 관심이 없거나 더 이상 테이블을 사용할 계획이 없을 때는요. 다행히 Lua에는 이것을 처리하는 또 다른 방법이 있습니다.

## `ipairs`

`ipairs`는 `for` 키워드와 함께 사용하는 함수로, 테이블 이름을 참조하지 않고 키와 값에 빠르게 접근할 수 있습니다! 문법은 이전 `for` 루프와 조금 다르지만 여전히 `for` 키워드를 사용합니다.

```lua
for my_key, my_value in ipairs(my_table) do 
    -- 무언가를 합니다!
end
```

이 예제에서는 `my_table`이라는 `table`이 있다고 가정합니다. `for`와 `end` 사이의 모든 코드 줄은 `my_key`와 `my_value`가 각각 `my_table`의 키와 해당 값으로 실행됩니다.

이전 `for` 루프처럼 오름차순으로 정렬됩니다. 즉 `1`에서 시작해 반복할 때마다 `1`씩 증가합니다. 하지만 키가 `string`이거나 숫자 사이에 빈틈이 있으면 작동하지 않습니다. 그런 경우에는 `pairs`를 사용해야 합니다.

## `pairs`

`pairs`는 `ipairs`와 비슷하지만, `1`부터 시작하는 연속된 정수가 아닌 키에서도 작동한다는 차이가 있습니다. 단점은 키가 나오는 순서를 신뢰할 수 없다는 것입니다.

<div class="runner">

```lua
my_table = {
    [3] = 7,
    ["name"] = 8,
    [false] = 4,
}

for key, value in pairs(my_table) do
    print(key)
    print(value)
end
```

</div>

키/값이 출력되는 순서는 신뢰할 수 없으며 실행할 때마다 달라질 수 있습니다. 그래도 모든 테이블을 순회할 수 있다는 장점이 있습니다!

## 게임으로 돌아가서
우리의 경우 각 게임의 `number_of_tries`를 기록하고 싶을 뿐입니다. 따라서 사용자 정의 키가 필요 없고, 인덱스를 `1`부터 시작해 매번 `1`씩 증가시키면 게임 번호에 대응됩니다!
