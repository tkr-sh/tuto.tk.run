```lua
number_to_guess = random(1, 100)
```

좋아요, 방금 변수에 데이터를 넣을 수 있다는 것을 봤습니다…… 그런데 이건 뭐죠???

이것이 무엇을 하는지 이해하려면 `function`(함수)을 이해해야 합니다. 이것은 첫 번째 줄에서 설명하지 않았던 데이터 타입 중 하나이므로, 이제 설명하겠습니다.

함수는 입력을 받아서 그것으로 무언가를 한 다음, 출력을 돌려주는 일종의 기계라고 생각할 수 있습니다.

## 그런데 입력으로 무엇을 하는 건가요??

Lua에는 특별한 일을 할 수 있게 해 주는 연산자들이 있습니다.

- `+`: 두 숫자를 더합니다. (예: `1 + 2` => `3`)
- `-`: 한 숫자에서 다른 숫자를 뺍니다. (예: `3 - 2` => `1`)
- `*`: 두 숫자를 곱합니다. (예: `3 * 2` => `6`)
- `/`: 한 숫자를 다른 숫자로 나눕니다. (예: `6 / 2` => `3`)

따라서 변수로 다음과 같은 일을 할 수 있습니다.
```lua
the_best_number = 40 + 2
my_grandpa_age = the_best_number * 2
```

`the_best_number`는 42가 되고, `my_grandpa_age`는 84가 됩니다.

## 함수로 돌아가서!

예를 들어, 함수는 숫자를 받아서 그 숫자에 `+ 1`을 한 값을 돌려줄 수 있습니다.

함수는 변수처럼 이름을 알면 사용할 수 있습니다. 하지만! 함수가 기계를 돌려서 출력을 내놓게 하려면 이름 뒤에 괄호를 붙여야 합니다(예: `my_function()`). 그러면 `my_function`이라는 함수가 실행됩니다. 그런데 이 함수에는 입력이 없습니다! 입력을 추가하려면 괄호 안에 원하는 값을 넣고 `,`로 구분하면 됩니다.

### 예시

```lua
day = 4
month = "4월"
year = 1984
calculate_tomorrows_date(day, month, year)
```
이것은 다음과 같습니다.
```lua
calculate_tomorrows_date(4, "4월", 1984)
```

## 두 번째 줄로 돌아가서

```lua
number_to_guess = random(1, 100)
```

즉, 이 줄은 `random` 함수를 입력 `1`과 `100`으로 실행하고, 계산 결과를 `number_to_guess`에 넣습니다. 우리는 `random`이 무엇을 하는지 정의한 적이 없습니다. 하지만 Lua에는 개발자를 돕기 위한 내장 함수들이 있습니다! 그리고 우리의 경우, 두 숫자를 입력으로 받아 첫 번째 숫자(여기서는 `1`)와 두 번째 숫자(여기서는 `100`) 사이의 무작위 숫자를 생성하는 `random` 함수가 있습니다.

완벽합니다! 이제 사용자가 맞혀야 할 숫자가 생성되었습니다!
