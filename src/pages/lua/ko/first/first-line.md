```lua
number_of_tries = 0
```

이것은 프로그램에서 처음 보는 줄입니다.

보통 프로그램이 무엇을 하는지 이해하고 싶을 때는, 일반 영어 글을 읽듯이 한 줄씩 읽습니다. 그래서 여기서 시작해 봅시다.


## 좋아, 그런데 이 줄은 무엇을 하는 거지?

프로그래밍 언어에서는 자주 "변수"라는 개념을 만나게 됩니다. 변수는 데이터를 담는 이름표가 붙은 상자와 같습니다. 변수를 한 번 만들면 그 내용을 읽을 수 있고(상자를 여는 것과 같습니다), 심지어 변경할 수도 있습니다("변수"라는 이름처럼요). 이는 상자에 새로운 값을 넣는 것과 같습니다.

### 그런데 어떤 데이터인가요?

Lua에는 지금 알아야 할 데이터 타입이 6[^1]가지 있습니다.
- `number`: 수학의 숫자와 같습니다! 그냥 적기만 하면 숫자를 선언할 수 있습니다: `123`.<br/> **참고**: 소수가 있는 숫자(예: `0.5`)에는 `,`(쉼표)가 아니라 `.`(점)을 사용하세요.
- `boolean`: `true` 또는 `false`입니다. (예: "2는 3과 같은가?" => `false`).
- `nil`: 비어 있음. `nil`의 목적은 값이 없다는 것을 말하는 것입니다.
- `string`: 글자, 숫자, 기호의 모음입니다(예: `안녕하세요!`). 문자열을 선언하려면 내용을 따옴표(`'` 또는 `"`)로 감싸야 합니다(예: 문자열 `안녕하세요!`를 얻으려면 `"안녕하세요!"`라고 써야 합니다).
- `table`: 나중에 살펴봅니다!
- `function`: 나중에 살펴봅니다!

변수에 데이터를 할당하고 싶을 때는 다음과 같이 쓰면 됩니다.
```lua
the_name_of_the_variable = the_value
```
`the_name_of_the_variable`은 무엇이든 될 수 있습니다. `true`, `false`, `nil`(그리고 나중에 보게 될 다른 것들)은 제외입니다.

`the_value`는 위에서 설명한 유효한 값입니다.

몇 가지 예입니다.
```lua
a_negative_number = -1
a_big_number = 100000000
grandpa_name = "철수"
no_value = nil
is_it_raining = false
```

변수의 내용을 다른 변수에 할당할 수도 있습니다.

```lua
grandpa_name = "철수"
my_grandpa_friend_name = grandpa_name
```

이 경우 `grandpa_name`과 `my_grandpa_friend_name`은 모두 문자열 `철수`가 됩니다.

## 첫 번째 줄로 돌아가서

```lua
number_of_tries = 0
```

즉, 이 줄은 숫자 `0`을 변수 `number_of_tries`에 넣는 것입니다. 그리고 이것은 실제로 말이 됩니다! 프로그램이 시작될 때 사용자는 아직 숫자를 추측하려고 하지 않았기 때문입니다! 그리고 `number_of_tries`라는 이름이 나타내듯이, 이 변수는 앞으로 사용자가 시도한 횟수를 담게 될 것입니다!
