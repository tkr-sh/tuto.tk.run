Полезная информация, которая нам нужна при работе с таблицами, — это «сколько в ней элементов?» Например, если я хочу получить последний элемент!

Это возможно благодаря специальному оператору: `#`. Написав `#`, а затем имя таблицы или саму таблицу, вы можете получить общий размер таблицы:


<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(#my_table)
my_table[4] = "d"
print(#my_table)
```

</div>

Это особенно полезно, если я хочу узнать элемент таблицы с «последним» индексом или если я хочу добавить новый элемент в конец: `my_table[#my_table]` — это значение, ключ которого равен общей длине таблицы, то есть в большинстве случаев последний!

<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(my_table[#my_table])
my_table[#my_table + 1] = "d"
print(my_table[#my_table])
```

</div>


### Крайние случаи

Оператор `#` надёжен только тогда, когда ключи таблицы — это целые числа `1, 2, 3, ...` без пропусков, начиная с `1`. Ключи, являющиеся строками или булевыми значениями, не учитываются, а если в середине пропущено число, результат непредсказуем:

<div class="runner">

```lua
-- Надёжно: ключи — это 1, 2, 3
print(#{ "a", "b", "c" }) -- 3
print(#{ [1] = "a", [2] = "b", [3] = "c" }) -- 3

-- Не учитывается: ключи — это строки
print(#{ ["a"] = 1, ["b"] = 2, ["c"] = 3 }) -- 0

-- Ненадёжно: есть пропуск по индексу 2
print(#{ [1] = "a", [3] = "b", [4] = "c" }) -- 1 или 4, не полагайтесь на это
```

</div>
