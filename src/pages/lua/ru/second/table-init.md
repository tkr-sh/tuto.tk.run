А что, если бы теперь у нас была история наших результатов, пока мы не закончим играть? История всего, что произошло? Как бы мы это сделали?

Ваш первый подход может состоять в том, чтобы определить несколько переменных, вот так:

```lua 
score_first_game = nil
score_second_game = nil
score_third_game = nil
...
```

Но это неправильный подход. Это нецелесообразно, если пользователь играет много раз. Это трудно чисто связать с циклом.

Чтобы решить это, нам понадобится новый тип данных: `table`.

## Что такое таблица?

`table` — это тип Lua, который позволяет нам хранить произвольно длинный или короткий объём данных. Каждая таблица Lua сопоставляет ключу значение в формате `[key] = value`, вот так:

```lua
my_table = {
    ["a"] = 7,
    ["b"] = 8,
    ["c"] = 4,
}
```

Мы можем получить доступ к значению таблицы, обратившись к ключу и сделав `my_table[my_key]`. Например:

<div class="runner">

```lua
my_table = { ["a"] = 7, ["b"] = 8, ["c"] = 4 }

print(my_table["b"])
```

</div>

И мы можем просто добавить новое значение в нашу таблицу, присвоив значение несуществующему ключу, вот так:

<div class="runner">

```lua
my_table = { ["a"] = 7, ["b"] = 8, ["c"] = 4 }

my_table["d"] = 5
print(my_table["d"])
```

</div>

Вы также можете не указывать ключ, и в этом случае ключи начнутся с единицы и будут увеличиваться дальше:


<div class="runner">

```lua
my_table = { "a", "b", "c", "z" }
-- То же самое, что
-- my_table = { [1] = "a", [2] = "b", [3] = "c", [4] = "z" }

print(my_table[2])
print(my_table[4])
```

</div>
