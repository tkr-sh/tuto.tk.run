Ещё один ключевой момент при работе с таблицами — перебор их элементов. Скажем, в нашей игре есть таблица `scores` (`score` — это `number_of_tries`, которое потребовалось пользователю, чтобы найти число). Как показать каждый результат каждой игры?

## `for index`
Во-первых, вы, возможно, помните ключевое слово `for`, о котором мы кратко говорили раньше:

<blockquote>

`for`: Последний цикл — это цикл `for`, и он несколько отличается, потому что вы уже знаете, сколько раз хотите повторить. И вы определяете, от какого числа до какого хотите итерироваться. В конце итерации он автоматически увеличит `age` на `1`!

<div class="runner">

```lua
for age = 0, 3 do
    print(age)
end
```
</div>

</blockquote>

Если мы свяжем это с нашими новыми знаниями об операторе `#`, мы сможем успешно перебрать таблицу!

<div class="runner">

```lua
scores = {
    [1] = 7,
    [2] = 8,
    [3] = 4,
}

for key = 1, #scores do
    print(key .. ": " .. scores[key])
end
```
</div>

Это отлично работает! Но писать `scores[key]` каждый раз для доступа к значению может быть немного избыточно, особенно если вам не важен ключ или вы не планируете больше использовать таблицу. К счастью, в Lua есть другой способ справиться с этим.

## `ipairs`

`ipairs` — это функция, которую мы будем использовать вместе с ключевым словом `for`, чтобы быстро получать доступ к ключу и значению без необходимости ссылаться на имя таблицы! Её синтаксис немного отличается от предыдущего цикла `for`, хотя она по-прежнему использует ключевое слово `for`:

```lua
for my_key, my_value in ipairs(my_table) do 
    -- Сделать что-нибудь!
end
```

В этом примере мы предполагаем, что у нас есть `table` с именем `my_table`. Каждая строка кода, находящаяся между `for` и `end`, будет выполняться с `my_key` и `my_value`, являющимися ключом и связанным значением из `my_table`. 

Как и предыдущий цикл `for`, он упорядочен по возрастанию. Это означает, что он начинается с `1` и увеличивается на `1` на каждой итерации. Но он не работает, когда ключи являются `string`, или если между числами есть пропуски. В этом случае следует использовать `pairs`.

## `pairs`

`pairs` похож на `ipairs`, с той разницей, что он работает с ключами, которые не являются последовательными целыми числами, начинающимися с `1`. Недостаток в том, что порядок, в котором приходят ключи, ненадёжен:

<div class="runner">

```lua
my_table = {
    [3] = 7,
    ["name"] = 8,
    [false] = 4,
}

for key, value in pairs(my_table) do
    print(key)
    print(value)
end
```

</div>

Порядок, в котором выводятся ключи/значения, ненадёжен и может меняться от одного запуска к другому. Однако у него есть преимущество: он позволяет перебрать любую таблицу!

## Возвращаемся к нашей игре
В нашем случае мы просто хотим сохранять `number_of_tries` для каждой игры. Поэтому пользовательские ключи не нужны, мы можем просто использовать индексы, начинающиеся с `1` и увеличивающиеся на `1` каждый раз, что соответствует номеру игры!
