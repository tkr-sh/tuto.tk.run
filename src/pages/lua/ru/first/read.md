```lua
user_guess = tonumber(read())
```

Итак, этот код может показаться странным (функция внутри функции?), но его можно рассматривать так:

```lua
read_value = read()
user_guess = tonumber(read_value)
```

Происходит следующее:
1. Lua хочет вычислить значение справа 
2. Lua хочет выполнить `tonumber`, но для этого ему нужно, чтобы все его входные данные имели значения
3. Поэтому, когда он видит `read()`, он сразу пытается её выполнить, чтобы функция выдала значение
4. После того как `read()` выполнилась и вернула значение, теперь можно выполнить `tonumber`!

### Хорошо, а что делает `read()`?

`read()` запрашивает у пользователя строку и захватывает её.

**Перед запуском примера:** не отключайте всплывающие окна для этого сайта, иначе вы больше не сможете использовать `read()`!



<div class="runner">

```lua
print(read())
```

</div>

### А как насчёт `tonumber`?

Поскольку `read()` получает от пользователя `string` (строку), мы не можем сравнить её с нашим случайным числом, потому что нельзя сравнивать `string`, в которой могут быть нецифровые символы, с `number` (например, `"x4%$A" > 3` не имеет смысла)

Поэтому нам нужно преобразовать ввод пользователя в число, и именно это и делает `tonumber`!

Эта функция вернёт `nil`, если её входные данные не являются допустимым числом.

<div class="runner">

```lua
print(tonumber("Not a number") == nil)
```

</div>

И вы не можете сложить `nil` + `number`, так что вводите допустимое число!

<div class="runner">

```lua
print(tonumber(read()) + 1)
```

</div>

Прочитает `string` от пользователя, преобразует её в `number` и прибавит к этому числу единицу, а если это не допустимое число, то `tonumber(read())` будет значением `nil`.
