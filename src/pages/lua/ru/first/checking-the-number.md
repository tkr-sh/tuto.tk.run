Теперь, когда мы знаем, как

1. сгенерировать случайное число
2. получить ввод пользователя
3. организовать цикл

Нам нужно помочь пользователю, сообщая ему, меньше или больше его догадка, чем секретное число.

Для этого мы будем использовать новое ключевое слово, которое вы часто будете использовать: `if`

`if` в основном выполняет код в зависимости от условия. Циклы проверяют условие, чтобы повторяться, а `if` проверяет условие, чтобы выполниться всего один раз.

Например, мы можем проверить, вводит ли пользователь `42`, и если да, поприветствовать его/её особым сообщением.
<div class="runner">

```lua
good_number = 42

if good_number == tonumber(read()) then
    print("Хороший выбор!")
end
```

</div>

Так что в нашей игре

```lua
if number_to_guess < user_guess then
    print("Загаданное число меньше!")
end

if number_to_guess > user_guess then
    print("Загаданное число больше!")
end
```

мы проверяем, меньше/больше ли число, и в зависимости от этого выводим сообщение, чтобы помочь пользователю.

Если пользователь нашёл правильное число, цикл остановится благодаря:

```lua
until user_guess == number_to_guess
```

<div class="runner">

```lua
number_to_guess = 42
user_guess = tonumber(read())

if number_to_guess < user_guess then
    print("Загаданное число меньше!")
end

if number_to_guess > user_guess then
    print("Загаданное число больше!")
end

if number_to_guess == user_guess then
    print("Правильно!")
end
```

</div>

И когда это сделано, нам остаётся только сделать хорошую концовку...
