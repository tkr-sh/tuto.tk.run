## Что считается `true`?

В условии Lua принимает не только `true` и `false`: можно использовать любое значение. Правило простое: `false` и `nil` считаются ложью, а **всё остальное** считается истиной.

Будьте осторожны, если вы знаете другой язык программирования: в Lua `0` и пустая строка `""` считаются истиной!

<div class="runner">

```lua
if 0 then
    print("0 считается истиной")
end

if "" then
    print("Пустая строка считается истиной")
end

if nil then
    print("Это никогда не выводится")
end
```

</div>

## Проверка на `nil` без `== nil`

Благодаря этому правилу мы можем проверить, что у переменной есть значение, используя её напрямую как условие:

<div class="runner">

```lua
local name = nil

if name then
    print("Привет, " .. name)
else
    print("Имени нет")
end
```

</div>

`if name then` — это более короткая запись `if name ~= nil then`, а `if not name then` — более короткая запись `if name == nil then`.

<div class="note">

Это не совсем одно и то же, когда переменная может содержать `false`: `false` — это не `nil`, но оно также считается ложью в условии.

</div>

## `not`

Ключевое слово `not` всегда даёт настоящий `boolean`. Оно даёт `true` для `false` и `nil` и `false` для всего остального:

<div class="runner">

```lua
print(not true)
print(not nil)
print(not 0)
print(not "hello")
```

</div>

## `or` и `and` возвращают одно из своих значений

Мы видели `or` и `and` с булевыми значениями, но они работают с любым значением и не всегда дают `boolean`: они возвращают одно из двух своих значений.

- `a or b` возвращает `a`, если оно считается истиной, иначе `b`.
- `a and b` возвращает `a`, если оно считается ложью, иначе `b`.

<div class="runner">

```lua
print(nil or "по умолчанию")
print("значение" or "по умолчанию")

print(nil and "дальше")
print("значение" and "дальше")
```

</div>

С `true` и `false` это даёт в точности те таблицы, которые мы видели раньше.

## Значения по умолчанию с `or`

Вот почему `or` может дать переменной значение по умолчанию, как мы делали для необязательных аргументов:

<div class="runner">

```lua
local name = nil
name = name or "Гость"

print(name)
```

</div>

Если у `name` есть значение, оно сохраняется. Если `name` равно `nil`, оно становится `"Гость"`.

## Выбор между двумя значениями

Используя `and` и `or` вместе, мы можем выбрать между двумя значениями с помощью условия в одной строке:

<div class="runner">

```lua
local score = 70
local result = score > 50 and "Вы победили!" or "Вы проиграли!"

print(result)
```

</div>

Это то же самое, что:

```lua
local result
if score > 50 then
    result = "Вы победили!"
else
    result = "Вы проиграли!"
end
```

<div class="note">

Этот приём не работает, если первое значение равно `false` или `nil`: `condition and false or "другое"` всегда даёт `"другое"`. В этом случае используйте обычный `if`.

</div>

## `and` останавливается, как только может

Когда первое значение `and` считается ложью, Lua даже не смотрит на второе. Помните ошибку, которая была у нас в начале курса при сравнении `nil` с числом? `and` позволяет её избежать:

<div class="runner">

```lua
local user_guess = nil

if user_guess ~= nil and user_guess > 10 then
    print("Догадка больше 10")
end

print("Никакой ошибки!")
```

</div>

Поскольку `user_guess ~= nil` равно `false`, `user_guess > 10` никогда не выполняется. Точно так же `or` не смотрит на своё второе значение, когда первое считается истиной.

## `nil` в таблицах

Ключ, которого нет в таблице, даёт `nil`, без какой-либо ошибки. А чтобы удалить ключ из таблицы, вы присваиваете ему `nil`:

<div class="runner">

```lua
local player = { name = "Bob", score = 42 }

print(player.age)

player.score = nil
print(player.score)
```

</div>

<div class="note">

Это правильный способ удалить такой ключ, как `score`, но не значение в списке: как мы видели, это создало бы дыру. Для списков используйте `table.remove`.

</div>
