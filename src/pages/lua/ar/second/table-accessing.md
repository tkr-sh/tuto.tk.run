معلومة مفيدة نحتاجها أثناء العمل مع الجداول هي "كم عدد عناصرها؟" على سبيل المثال إذا أردت الحصول على العنصر الأخير!

هذا ممكن بفضل عامل خاص: `#`. بكتابة `#` ثم اسم الجدول أو الجدول مباشرةً، يمكنك الحصول على الحجم الكلي للجدول:


<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(#my_table)
my_table[4] = "d"
print(#my_table)
```

</div>

هذا مفيد بشكل خاص إذا أردت معرفة عنصر جدول بالفهرس "الأخير"، أو إذا أردت إضافة عنصر جديد في النهاية: `my_table[#my_table]` هو القيمة التي يكون مفتاحها الطول الكلي للجدول، أي العنصر الأخير في معظم الحالات!

<div class="runner">

```lua
my_table = { "a", "b", "c" }

print(my_table[#my_table])
my_table[#my_table + 1] = "d"
print(my_table[#my_table])
```

</div>


### الحالات الحدّية

العامل `#` موثوق فقط عندما تكون مفاتيح جدول ما هي الأعداد الصحيحة `1, 2, 3, ...` دون فجوات ابتداءً من `1`. المفاتيح التي هي سلاسل نصية أو boolean لا تُحتسب، وإذا كان رقم مفقودًا في الوسط، فالنتيجة غير متوقّعة:

<div class="runner">

```lua
-- موثوق: المفاتيح هي 1، 2، 3
print(#{ "a", "b", "c" }) -- 3
print(#{ [1] = "a", [2] = "b", [3] = "c" }) -- 3

-- غير محتسب: المفاتيح سلاسل نصية
print(#{ ["a"] = 1, ["b"] = 2, ["c"] = 3 }) -- 0

-- غير موثوق: هناك فجوة عند الفهرس 2
print(#{ [1] = "a", [3] = "b", [4] = "c" }) -- 1 أو 4، لا تعتمد عليه
```

</div>
