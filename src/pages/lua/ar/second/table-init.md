ماذا لو الآن، كان بإمكاننا أن يكون لدينا سجلّ لنتائجنا، حتى ننهي اللعب؟ سجلّ لكل ما حدث؟ كيف نفعل ذلك؟

نهجك الأول قد يكون تعريف عدّة متغيّرات هكذا:

```lua 
score_first_game = nil
score_second_game = nil
score_third_game = nil
...
```

لكن هذا ليس نهجًا صحيحًا. هذا غير مستدام إذا لعب المستخدم مرات كثيرة. من الصعب ربطه بحلقة بشكل نظيف حقًّا.

لحلّ هذا، سنحتاج إلى نوع بيانات جديد: `table`.

## ما هو الجدول (table)؟

`table` هو نوع في Lua يسمح لنا بتخزين كمية من البيانات ذات طول عشوائي، قصيرة أو طويلة. كل جدول Lua يُسند مفتاحًا إلى قيمة بالصيغة `[key] = value`، هكذا:

```lua
my_table = {
    ["a"] = 7,
    ["b"] = 8,
    ["c"] = 4,
}
```

يمكننا الوصول إلى قيمة جدول بالإشارة إلى المفتاح وفعل `my_table[my_key]`. على سبيل المثال:

<div class="runner">

```lua
my_table = { ["a"] = 7, ["b"] = 8, ["c"] = 4 }

print(my_table["b"])
```

</div>

ويمكننا ببساطة إضافة قيمة جديدة إلى جدولنا بإسناد مفتاح غير موجود إلى قيمة هكذا:

<div class="runner">

```lua
my_table = { ["a"] = 7, ["b"] = 8, ["c"] = 4 }

my_table["d"] = 5
print(my_table["d"])
```

</div>

يمكنك أيضًا عدم كتابة أي مفتاح، وفي هذه الحالة، ستبدأ المفاتيح من واحد وتزيد بعد ذلك:


<div class="runner">

```lua
my_table = { "a", "b", "c", "z" }
-- نفس
-- my_table = { [1] = "a", [2] = "b", [3] = "c", [4] = "z" }

print(my_table[2])
print(my_table[4])
```

</div>
